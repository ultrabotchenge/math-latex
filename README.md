# Math Equation Editor

Визуальный редактор математических формул с экспортом в LaTeX.

## Возможности

- Предпросмотр формул в реальном времени
- Панель математических символов (±, ∞, α, β, γ и т.д.)
- Структуры: дроби, индексы, корни, интегралы, матрицы
- Экспорт в PNG/SVG
- Копирование LaTeX кода
- История формул
- Быстрые шаблоны

## Использование

1. Откройте `index.html` в браузере
2. Нажимайте на символы и структуры для вставки
3. Редактируйте формулу в текстовом поле
4. Копируйте LaTeX код или экспортируйте изображение

## Технологии

- React + TypeScript
- KaTeX (рендеринг формул)
- Tailwind CSS
- html-to-image (экспорт)
